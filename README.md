# 오늘의 명언 생성기

키워드를 기반으로 명언을 생성하고, 복사/공유하며, 직접 명언을 추가할 수 있는 웹 앱입니다.

## 주요 기능

- **키워드 기반 생성**: 입력한 키워드로 맞춤형 명언 생성
- **랜덤 명언 표시**: `다음 명언` 버튼으로 랜덤 명언 전환
- **저자명 표시**: 명언 텍스트와 함께 `— 저자명` 형식으로 출력
- **클립보드 복사**: 현재 명언을 `복사` 버튼으로 즉시 복사
- **공유 기능**:
  - `http://`, `https://` 환경에서는 Web Share API 시도
  - 로컬(`file://`) 등 제한 환경에서는 공유 옵션 패널(이메일/SNS/URL 복사) 제공
- **나만의 명언 추가**:
  - 명언(최대 300자), 저자명(최대 100자) 입력 후 데이터에 추가
  - 추가된 명언은 이후 랜덤 명언 목록에 포함
- **토스트 메시지 UI**: 복사/공유/입력 검증 결과를 화면 메시지로 안내

## 프로젝트 구조

- `index.html`: 페이지 구조 및 UI 요소
- `styles/main.css`: 레이아웃/반응형/토스트/공유 옵션 스타일
- `scripts/app.js`: 명언 데이터/생성/공유/복사/추가 로직

## 실행 방법

### 1) 빠르게 실행

1. 프로젝트 폴더를 엽니다.
2. `index.html` 파일을 브라우저에서 실행합니다.

### 2) 권장 실행 (공유 기능 안정)

브라우저 보안 정책으로 `file://` 환경에서는 일부 공유 기능이 제한될 수 있어, 로컬 서버 실행을 권장합니다.

```bash
# Python 3
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## 사용 방법

1. 키워드를 입력하고 `다음 명언`을 눌러 명언 생성
2. `복사` 버튼으로 현재 명언 복사
3. `공유` 버튼으로:
   - 지원 환경: 시스템 공유 시트 실행
   - 제한 환경: 이메일/SNS/URL 복사 옵션 사용
4. `나만의 명언 추가하기`에서 명언/저자 입력 후 `추가`
