# 오늘의 명언 생성기

랜덤 명언을 확인하고, 복사/공유하며, 직접 명언을 추가할 수 있는 웹 앱입니다.

## 주요 기능

- **2단 카드 레이아웃**: 연한 회색 배경 위에 명언 카드 + 사용자 입력 카드 세로 배치
- **카드 디자인**: 흰 배경, 16px 라운드, subtle 그림자, 넉넉한 내부 여백
- **랜덤 명언 표시**: `다음 명언` 버튼으로 랜덤 명언 전환
- **명언 표시 스타일**: 큰 텍스트와 인용부호(`" "`) 스타일 적용
- **클립보드 복사**: 현재 명언을 `복사` 버튼으로 즉시 복사
- **버튼 비율/아이콘**: `다음 명언(🔄)`, `복사(📋)`, `공유(🔗)` 버튼을 2:1:1 비율로 배치
- **공유 기능**:
  - `http://`, `https://` 환경에서는 Web Share API 시도
  - 로컬(`file://`) 등 제한 환경에서는 공유 옵션 패널(이메일/SNS/URL 복사) 제공
- **나만의 명언 추가**:
  - 명언/저자 라벨 필수 표시(`*`) 제공
  - 명언(최대 300자), 저자명(최대 100자) 입력 후 데이터에 추가
  - 추가된 명언은 이후 랜덤 명언 목록에 포함
- **토스트 메시지 UI**: 복사/공유/입력 검증 결과를 화면 메시지로 안내
- **입력 UI 스타일**: 명언/저자 입력창은 연한 회색 배경, 무테두리 디자인 적용
- **모바일 반응형**: 작은 화면에서도 카드/버튼 레이아웃이 자연스럽게 유지

## 프로젝트 구조

- `index.html`: 페이지 구조 및 UI 요소
- `styles/main.css`: 카드 레이아웃/버튼/입력 UI/반응형/공유 옵션/메시지 스타일
- `scripts/app.js`: 명언 데이터/생성/공유/복사/추가/테마 전환 로직

## 실행 방법

### 1) 빠르게 실행

1. 프로젝트 폴더를 엽니다.
2. `index.html` 파일을 브라우저에서 실행합니다.

### 2) 권장 실행 (공유 기능 안정)

브라우저 보안 정책으로 `file://` 환경에서는 일부 공유 기능이 제한될 수 있어, 로컬 서버 실행을 권장합니다.

```bash
# Python 3
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## 사용 방법

1. `다음 명언` 버튼으로 랜덤 명언 생성
2. `복사` 버튼으로 현재 명언 복사
3. `공유` 버튼으로:
   - 지원 환경: 시스템 공유 시트 실행
   - 제한 환경: 이메일/SNS/URL 복사 옵션 사용
4. `나만의 명언 추가하기`에서 명언/저자 입력 후 `추가`
